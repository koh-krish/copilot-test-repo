# Copilot PR Review Test Project

This is a basic Express.js project created to test GitHub Copilot's PR review feature. The code intentionally contains some natural development mistakes for testing purposes.

## How to Run

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the server:
   ```sh
   npm start
   ```

## Intentional Mistakes
- Missing middleware (e.g., body-parser)
- Incorrect variable name in `app.listen`
- Missing semicolons
- No error handling middleware
- No error handling in route

> These are for PR review testing only.
